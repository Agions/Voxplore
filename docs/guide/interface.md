# 🖥️ 界面与功能指南

Vynaro 采用 **Tauri 2 + React 19** 深度研发，提供直观的暗黑影院级桌面端界面，将复杂的 AI 视频解说与短剧剪辑流程拆解为 7 步标准化卡片流水线。本页为您介绍界面布局、工具栏与核心功能视窗。

---

## 🎨 界面全景布局

![Vynaro 全景工作台 UI Mockup](/assets/mockups/hero-app-main.jpg)

### 主界面四大核心区域

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 🎬 Vynaro Desktop   [工作区]  [7步流水线]  [AI服务配置]   [主题] [导出] │  ← 1. 顶部标题与导航栏
├───────────┬───────────────────────────────────┬────────────────────────┤
│ 📥 素材   │ 🤖 AI 独白脚本编辑器               │ 🎬 9:16 竖屏视频预览器 │
│ ✂️ 拆条   │ ───────────────────────────────── │ ────────────────────── │
│ 🎙️ 配音   │ Hook: 黄金3秒引人入胜...           │                        │
│ 📝 字幕   │ Body: 矛盾爆发与故事推进...       │                        │
│ 📤 导出   │                                   │                        │
├───────────┴───────────────────────────────────┴────────────────────────┤
│ 🎞️ 多轨音画混流时间轴 (视频轨 / 独白语音轨 / BGM轨 / SFX轨 / 50ms字幕轨)   │  ← 4. 底部时间轴
└────────────────────────────────────────────────────────────────────────┘
```

1. **顶部导航栏**：展示工程名称、当前项目状态、全局 API Key 配置入口与【一键导出】操作按键。
2. **左侧 7 步卡片流水线 DAG 控制树**：按顺序导航与查看 `素材导入 → 智能拆条 → AI独白 → TTS克隆 → VAD字幕 → 音画混流 → 剪映/平台导出` 运行状态。
3. **中央智能编辑区**：根据左侧选中的卡片步数，切换场景拆面视窗、独白脚本编辑器、声波调整器或导出参数设置。
4. **右侧 9:16 / 16:9 实时预览器**：内置硬件加速播放器，支持 1080P/4K 视频实时播放、逐帧步进（Scrubbing）与画面比例裁切预览。

## ✂️ 核心模块 UI 视窗说明

### 1. Step 2: FFmpeg 智能拆条视窗

![FFmpeg 智能拆条视窗 UI](/assets/mockups/scene-split-ui.jpg)

* **关键帧序列条（Film Strip Gallery）**：自动提取视频的关键帧缩略图，按时间顺序罗列。
* **情绪峰值与镜头切面曲线图**：通过 FFmpeg 场景探测 (`select='gt(scene,0.3)'`) 与音频振幅，直观展示镜头分割点与冲突高潮点。
* **视频元数据 Inspector**：自动解析输入视频的 Resolution、FPS、Video Codec (H.264/HEVC)、Audio Bitrate 与 Duration。

---

### 2. Step 3: AI 独白脚本生成视窗

![AI 独白脚本生成视窗 UI](/assets/mockups/ai-script-generator.jpg)

* **大模型切换面板**：下拉选择通义千问 (Qwen 3.8)、DeepSeek R1、GPT-4o、Claude 3.5 等 11 大主流 LLM 服务商。
* **黄金 4 阶段结构卡片**：
  * **Hook (引子)**：黄金 3 秒，抛出冲突与核心悬念。
  * **Body (主体)**：剧情平铺与人物内心独白。
  * **Counter-attack (反转/高潮)**：剧情峰值与逆袭桥段。
  * **Conclusion (结语/钩子)**：引导点赞关注与下集预告。
* **多模型交叉审核指标 (Consensus Strength)**：显示脚本完播率预估评分与建议修改标记。

---

### 3. Step 4 & 5: TTS 人声克隆与 VAD 字幕对齐

![TTS 人声克隆与 VAD 字幕对齐 UI](/assets/mockups/tts-voice-waveform.jpg)

* **黄金声波面板 (Golden Waveform)**：可视化实时渲染 TTS 合成的音频波形图与音量包络线。
* **人声克隆探针 (Voice Clone Probe)**：基于 GPT-SoVITS 零样本音色克隆，仅需 5 秒参考音频即可复刻特定解说声线。
* **FFmpeg silencedetect 端点检测**：自动探测人声停顿点，实现低于 50ms 的字幕与配音精准对齐。

---

### 4. Step 7: 剪映草稿 (.draft) 与多平台导出

![剪映草稿与多平台导出 UI](/assets/mockups/capcut-export-modal.jpg)

* **剪映工程草稿导出 (`.draft`)**：生成剪映 PC 端原生工程草稿文件夹，包含轨道 JSON、媒体资源相对路径与字幕样式，方便在剪映中二次精细微调。
* **8 大平台一键发布预设**：
