## ⚙️ 系统快捷键指南

| 快捷键 (macOS / Win) | 功能描述 |
| :--- | :--- |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + <kbd>N</kbd> | 创建新的短剧解说工程 |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + <kbd>I</kbd> | 导入本地视频素材片段 |
| <kbd>Space</kbd> | 播放 / 暂停视频预览 |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> | 快捷弹出【导出与剪映草稿】视窗 |
