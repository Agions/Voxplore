# 🖥️ 三栏集成工作台操作指南

splicr 采用 **三栏一体化专业影视解说工作台 (Integrated Cinema Studio)** 设计，单屏打通“素材拆条 ➔ 5 轨时间轴 ➔ Multi-Agent 编剧/配音 ➔ 原生剪映草稿交付”。

---

## 🏛️ 三栏架构布局全景

```text
+---------------------------------------------------------------------------------------------------------------+
|  TopBar: splicr 叙影 Logo | 工程名称 | 渲染引擎/Metal加速状态 | 全局操作 (新建/导入/一键执行流水线) | 主题/语言/设置   |
+---------------------+-------------------------------------------------------+---------------------------------+
| 【左栏: 生产流水线】 | 【中栏: 视听中枢与多轨时间轴】                        | 【右栏: AI创作与模型控制台】     |
| (280px)             | (Flex-1 自适应)                                       | (380px)                         |
|                     |                                                       |                                 |
| 1. 6 大 Agent 状态  | 1. 1080×1920 9:16 短剧竖屏播放器                      | 1. Multi-Agent 协同视窗         |
| 2. 镜头切片分镜列表 |    - 0~3s 黄金 Hook 视窗标记                          |    - 思考流 / 行动日志          |
|    - 情绪峰值识别   | 2. 48 频段 FFT Canvas 实时声波频谱                    |    - Human-in-the-Loop 断点审批 |
|    - 毫秒级时间打点 | 3. 5 轨磁性多轨时间轴 (MultiTrack Timeline):          | 2. AI 第一人称剧本撰写          |
|                     |    - V1 视频切片轨                                    | 3. GPT-SoVITS 人声克隆          |
|                     |    - HK 0~3s 黄金 Hook 轨                             | 4. 剪映工程草稿 (.draft) 导出   |
|                     |    - A1 第一人称配音轨                                |                                 |
|                     |    - SUB 逐字高亮字幕轨                               |                                 |
|                     |    - BGM 动态闪避混流轨 (-18%)                        |                                 |
+---------------------+-------------------------------------------------------+---------------------------------+
```

## ⚙️ 系统快捷键指南

| 快捷键 (macOS / Win) | 功能描述 |
| :--- | :--- |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + <kbd>N</kbd> | 创建新的短剧解说工程 |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + <kbd>I</kbd> | 批量导入本地视频素材片段 |
| <kbd>Space</kbd> | 播放 / 暂停视听中枢与时间轴预览 |
| <kbd>Cmd</kbd> / <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> | 快捷导出剪映工程草稿 (`.draft`) |
